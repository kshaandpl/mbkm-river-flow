Pengaturan ServerMax

Ubah nilai ServerMax secara manual tanpa perlu mengedit coding Python.

Konfigurasi Node

ServerMax dipakai bersama LevelMM dari MQTT untuk menghitung level air.

Node Lokasi ServerMax (mm) Sensor Hujan Sensor Flow Aksi
Memuat konfigurasi...
Catatan: setelah ServerMax diubah, nilai level air dihitung ulang dari LevelMM terbaru dan ServerMax baru. Data MQTT berikutnya juga akan memakai ServerMax baru saat masuk ke database.

Rumus yang dipakai

Level air (m) = (LevelMM - ServerMax) / 1000

LevelMM berasal dari MQTT. ServerMax berasal dari tabel konfigurasi dan bisa diubah manual di dashboard ini.

Curah hujan bernilai 0 tetap ditampilkan di grafik sebagai titik/garis pada angka 0. Nilai -99 berarti data tidak tersedia, bukan nol.

Flow rate masih ditampilkan sebagai belum ada sensor karena sensor debit belum tersedia.
